# Приложение Playlist Maker для создания плейлистов из любимых песен

## Описание: 
В качестве базы аудиозаписей используется сервис iTunes, который позволяет искать по всей публично доступной библиотеке iTunes.
База iTunes предоставляет возможность прослушивать отрывки найденных аудиотреков.
В приложении есть возможность добавление треков в избранное и добавление треков в плейлисты.

## Используемый стек:
* MVVM 
* Room 
* Retrofit 
* Koin 
* Glide
* LiveData
* Coroutines
